# DDS Manager 0.7.0

### ✨ Added & Improved / 新增与优化
- 新增全网 UUID 封禁，支持封禁、解封、查询和登录拦截。(Added network-wide UUID bans with management commands and login enforcement.)
- 新增九语言支持及自定义语言包热重载。(Added nine built-in languages and reloadable translations.)
- 优化控制台二次确认及配置文件中英双语注释。(Improved console confirmations and bilingual configuration comments.)

### 🐛 Fixed / 修复
- 修复封禁数据异常可能影响登录安全、语言匹配与翻译回退的问题。(Hardened ban-data validation and language fallback.)
- 移除冗余的语言包加载日志。(Removed redundant language-pack startup logs.)

### 🔧 Compatibility / 兼容性
- 通过六个 Velocity 稳定版本的构建测试（3.4.0、3.5.1、4.0.0、4.1.0、4.1.1、4.2.0），插件字节码目标为 Java 17。(Tested against six stable Velocity versions; targets Java 17 bytecode.)
